## 改了什么

| 项 | v3.2 | v3.3 |
| --- | --- | --- |
| 错价模型下限 | 无 | 买入方向 ≥ 0.56 |
| 混合权重 | 0.70 模型 / 0.30 市场 | 0.55 / 0.45 |
| 错价 edge | ≥ 4pp，无上限 | 4pp–15pp（冷板块下限仍 ×1.5） |
| 错价价格 | 0.25–0.75 | 0.35–0.65 |
| 错价试探 $1 | edge 在 [2pp, 4pp) | 关闭 |
| Live 试探 $1 | [2pp, 4pp) | 不变 |
| 动量试探 $1 | 距离 [2, 4) bps | 不变 |
| BBO | 45 秒内直接新鲜，安静窗口到 5 分钟 | 30 秒，安静窗口到 3 分钟 |
| 默认仓位 | $2 | $2 |
| 现金保留 | ≥ $15 | ≥ $15 |
| 日帽、板块刹车 | 不变 | 不变 |

这组门控会挡掉已结算的那一整团硬币模型错价，包括那 3 笔赢单。目的是停止这个负期望的总体，而不是把历史赢单挑回来。模型公式可以到 0.90；以后只有买入方向模型 ≥ 0.56、价格在带内、收缩后 edge 在 4–15pp 才下 $2。

10 月 17 日多笔亏损是 API 已经 `stale_bbo` 之后的浏览器补单。代码只收紧 BBO，不恢复浏览器补单。
