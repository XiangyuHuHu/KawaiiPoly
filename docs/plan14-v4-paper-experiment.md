# Plan14 v4 模拟实验

版本：`plan14_5m_risk_guard_v4`。保持自动模拟开启，不重置现金和历史，不启用实盘。

## 本轮修改

- 保持 v3 的入场概率模型、权重、扣费优势门槛和 5m 范围不变。模型输出不是已校准的真实胜率，取消“已校准”标记。
- 同一 5m 窗口、同一方向，跨币种最多成交一笔。提前平仓也不释放本窗口名额，零金额未成交记录不占名额。
- 同次扫描的候选按当前模型估计 edge 排序，不按固定币种顺序抢占名额。该排序不代表经过验证的盈利优势。
- v4 订单按新鲜买一价计算“净份数 × 买一价 − 卖出费”。相比投入金额亏损达到 25% 时，风险退出不等普通模型的 10 秒 / 3 次确认，也不依赖现货模型可用。没有有效新鲜买价则不能虚构成交。
- 25% 是实验触发阈值，不是保证最大亏损。轮询、价格跳变、无买盘、实际深度都会使真实成交更差；模拟仍按当前买一计算，没有新增深度成交模拟。
- 普通模型止损继续使用 10 秒 / 3 次确认；旧版订单保留原退出规则。新旧退出结果均按官方结算结果回填持有对照。
- 单笔 3% 可用现金的预算不再被最低下单份数反向抬高；达不到最低份数则跳过。

## 可核查记录

每笔保存最新退出判断、最多 256 条判断轨迹、首个止损触发快照（独立保存）、当时报价扣费可实现盈亏，以及轨迹截断数和输入获取失败次数。盘口采样时间是 HTTP 取回时间，不是成交所时间；过期盘口不用于 v4 模拟退出。

这些记录能解释等待和重置过程，但不是完整的旧版影子策略：新策略退出后不会继续采样该持仓，不能据此宣称已经做过同路径新旧规则 A/B 测试。

## 评估方式

运行 `node scripts/report-plan14-risk.mjs` 查看 v3 / v4 分版本的成交笔数、投入、净收益、每笔收益、成交额收益率、退出分类和官方持有对照覆盖数。

先检查执行正确性与记录完整性，再检查扣费收益和风险退出后反而本可获胜的比例。至少分日期/窗口查看，不把相关币种当独立样本；不能仅因交易减少、总亏损下降就认定入场优势改善。本轮不根据这两天数据继续调整模型权重，也不承诺盈利。
